# 檐语 · 垂帘

Vite + React 19。横向卡片轮播 + Canvas 手写 Verlet 链式下坠文字帘，
文字挂载锚点动态咬合屋顶轮廓。

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run shots    # 逐张截图 + 自检（需要 dev 已启动）
npm run build
```

## 结构

| 文件 | 作用 |
| --- | --- |
| `src/App.jsx` | 轮播容器：拖拽切换、背景主色调渐变过渡 |
| `src/components/RoofCard.jsx` | 单卡：屋顶图 / 轮廓扫描 / 建帘 / RAF 循环 |
| `src/lib/profile.js` | Canvas 逐列扫描 alpha，生成轮廓 Profile |
| `src/physics/verlet.js` | Verlet 积分、距离约束、边缘反弹 |
| `src/physics/curtain.js` | 字帘：建绳、风、鼠标交互、消融渲染、自检 |
| `scripts/gen-roofs.mjs` | 生成 5 张屋顶素材（透明底 SVG） |
| `scripts/shoot.mjs` | 三种视口逐张截图与量化验证 |

## 物理与消融参数

`src/physics/verlet.js` 的 `PHYSICS`：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `GRAVITY` | 0.28 | 重力 |
| `FORCE` | 0.025 | 风 / 外力系数 |
| `BOUNCE` | 0.6 | 边缘弹性反弹 |
| `DAMPING` | 0.986 | 速度阻尼 |
| `ITERATIONS` | 6 | 约束松弛迭代 |
| `BEND` | 0.055 | 抗弯，纸帘感 |
| `POINTER_RADIUS/PUSH/DRAG` | 92 / 0.42 / 0.22 | 光标推开半径、强度、拖带 |

右下角消融：`alpha = 1 - dissolveWeight * 0.8`，只作用于 `fillText` 时的透明度。
消融权重不进入任何约束，悬绳始终按原样完整连结。

## 轮廓咬合

1. 屋顶图 `onLoad` 后画进离屏 Canvas。
2. 逐列扫描：自上而下第一个不透明像素得到 `top`，自下而上得到 `bottom`（檐口下沿）。
3. 结果按 0~1 归一化缓存，随卡片尺寸缩放。
4. 每列文字的锚点 = 檐口下沿再往上 2px，弧线怎么走，字头就怎么排。

素材（`scripts/gen-roofs.mjs`）刻意保证屋顶底缘是每一列最靠下的不透明像素：
层间壁、破风、擬宝珠都画在下层轮廓之上，不会污染 Profile。

## 踩过的坑（都已在代码里注释）

- **逐字 `setTransform` 会覆盖 DPR 变换**，高分屏上字缩到左上角、和绳子分家。
  必须 `save/translate/rotate/restore` 叠加在既有变换上。
- **物理全程用 CSS 像素**，DPR 只作用于 `ctx`；混进物理量等于放大重力，粒子会砸到底部堆叠。
- **松弛法解不完长链**：重力把绳拉长，越往下字距越开，末端坠到底边挤成一堆。
  收尾加一遍自锚点向下的定距投影，绳子彻底不可伸长。
- **风的波长必须远大于帘宽**，否则左右两半往相反方向倒，列一长就互相穿插；
  再加一道相邻列横向最小间距约束兜底。
- **高度测量失败就不建帘**（`rootRect.height < 160` 直接返回等下一帧），
  否则字数按 0 高度算出来会漏出大片空隙。

## 验证

`npm run shots` 在 1440×900@1x、1440×900@2x、414×812@2x 三种视口逐张检查并截图到 `shots/`：

- 建帘是否成功、绳数是否异常偏少（高度测量失败）
- 底部贴边粒子数（堆叠）与帘底余量
- 锚点漂移（咬合是否失效）、列间最大空隙
- Canvas 后备缓冲与 CSS 尺寸的比值是否等于 DPR
- **墨迹包围盒 vs 物理包围盒**：把画布上真实像素的包围盒换算回 CSS 像素与粒子包围盒比对，
  任何变换 / DPR 错位都会在这里露馅

另外会输出光标横扫推开、移开回弹、拖拽中间态与落位四张交互截图。
